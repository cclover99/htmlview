# HTML View

True scale web screenshot viewer with an optional right click context menu entry for quick access.

#### Compile (MinGW):  
```cmd
g++ -O2 ./launcher/src/launcher.cpp -o ./launcher/bin/launcher.exe -mwindows
```

#### Install context menu entry
```powershell
.\install.ps1
```

#### Uninstall context menu entry
```powershell
.\uninstall.ps1
```
